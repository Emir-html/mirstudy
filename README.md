Подготовка к ЕГЭ по обществознанию: 76 полных уроков по кодификатору 2026, тесты с автопроверкой, карточки,
вторая часть, шпаргалки, план подготовки по дням, «Интенсив» перед экзаменом, поиск по урокам и умный ответ.

- Прогресс хранится в браузере на устройстве ученика и сохраняется при обновлениях сайта.
- Перенести прогресс на другое устройство: Профиль → «Перенос прогресса» → скачать файл → загрузить там.
- Новые версии подгружаются сами по той же ссылке (появляется плашка «Сайт обновился»).
- После первого открытия работает и без интернета.
- На телефон как приложение: Safari → «Поделиться» → «На экран „Домой“», Chrome → «Установить приложение».
