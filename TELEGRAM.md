# МирСтади в Telegram — как подключить бота (5 минут)

Сайт уже умеет работать как мини-приложение Telegram. Нужно только создать бота и указать ему ссылку.

1. Откройте в Telegram **@BotFather** → `/newbot`.
   - Имя (видят все): `МирСтади — ЕГЭ обществознание`
   - Адрес бота (латиница, в конце `bot`): например `mirstudy_bot`
2. Ссылка на приложение: в @BotFather откройте **My Bots → ваш бот → Bot Settings → Configure Mini App → Enable Mini App**
   и вставьте `https://emir-html.github.io/mirstudy/`.
   После этого у бота появится кнопка «Открыть» в профиле, а ссылка `https://t.me/<адрес_бота>?startapp` откроет приложение сразу.
3. Кнопка меню в чате с ботом: **Bot Settings → Menu Button → Configure menu button** → та же ссылка, текст `Учиться`.
4. Оформление (по желанию): `/setuserpic` — иконка (`icons/icon-512.png` из репозитория), `/setdescription` —
   «Подготовка к ЕГЭ по обществознанию: уроки, тесты, карточки, вторая часть. Прогресс сохраняется в Telegram.»,
   `/setabouttext` — «Тренажёр ЕГЭ по обществознанию».

## Ссылки сразу в нужный раздел
`https://t.me/<адрес_бота>?startapp=<код>`

| Код | Куда ведёт |
|---|---|
| `t_3-2` | тема 3.2 |
| `cs_24` | шпаргалка к заданию 24 |
| `p2_25` | задания № 25 |
| `int` | интенсив |
| `tests`, `cards`, `plan`, `profile`, `cheatsheets`, `topics` | разделы |

## Что происходит внутри
- Вход — по аккаунту Telegram (он уже подтверждён номером телефона), пароль не нужен. Имя и фото берутся из Telegram, их можно поменять в профиле.
- Прогресс хранится на устройстве и в облаке Telegram этого пользователя — на другом телефоне или компьютере с тем же аккаунтом всё на месте. Без связи всё работает, синхронизация догонит.
- Обновления: публикуете новую версию сайта по той же ссылке — в Telegram она откроется сама.
